# RAG Kominfo

A simple Retrieval-Augmented Generation (RAG) and query program me and my team made during my internship at Diskominfo Kota Semarang.

## 📝 Overview

This project lets you ask questions based on the content of PDF files. Here's what it does:

1. **Extracts text** from PDF files and saves it to a local database (using ChromaDB).
2. **Answers your questions** by searching the database and generating a response using OpenAI.

The system uses:
- **LangChain**
- **ChromaDB**
- **OpenAI API**

It's a basic prototype to show how AI can help make searching through documents easier.
